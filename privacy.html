Privacy Policy for mc_server

Last updated: November 1, 2026

Purpose and operator

mc_server is a personal backup utility operated by the owner of this Google OAuth application. It is used to store Minecraft server backups in the owner's Google Drive. It is not a public service.

Google data and permissions

The utility uses Google OAuth authorization and the Google Drive API through rclone. Its current configuration requests the https://www.googleapis.com/auth/drive scope, which grants broad access to Google Drive files. The utility is configured to operate in a designated backup folder. This folder restriction is an application setting, not a limitation of the granted OAuth scope. Google may also return account-identifying information as part of the authorization process.

Use of data

Google Drive access is used to upload backup archives, list and inspect backup file metadata, verify uploaded file checksums, and remove outdated backup archives according to the configured retention policy. The utility does not intentionally access unrelated Drive file contents.

Backup archives can contain Minecraft world data, player names, UUIDs, player progress, and selected server configuration. OAuth credentials and server secrets are excluded from the backup archives by the backup configuration.

Storage and security

Backup archives are stored on the owner's server and in Google Drive. OAuth credentials and tokens are kept locally on the server in a restricted-access configuration file. They are not published on this website or in its source repository. The owner controls sharing permissions for the backup folder.

Sharing and other uses

Google Drive receives the uploaded backup data. The utility does not sell Google user data or use it for advertising, profiling, or training AI models. The utility does not intentionally disclose backup data to other third parties. Access may be available to people whom the owner authorizes through file or folder sharing.

Google Drive is subject to Google's own terms and privacy policy. This informational website is intended for hosting on GitHub Pages, which may process normal website request information under GitHub's privacy policy. The website has no access to the utility's OAuth tokens or backup archives. It contains no analytics, forms, third-party scripts, or tracking pixels.

Retention and deletion

The current cloud retention policy keeps the newest backup for each of the two most recent distinct backup dates. Older application backup archives may be permanently deleted after a successful, verified upload. Local archives that have not been successfully uploaded may be retained for retry. The owner can manually delete local and cloud backup files.

Revoking access

The owner can revoke the application's Google access in their Google Account's third-party connections settings and remove the local OAuth configuration. Revoking access stops future authorized operations; it does not automatically delete existing local or Google Drive backups.

Contact and changes

Contact the operator through GitHub Issues. Issues are public; please do not include credentials, backup files, or private player information. This page will be updated if the utility's data handling changes.
